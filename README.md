# 婚禮賓果 Wedding Bingo

> 一個為婚禮派對設計的互動賓果遊戲，打開網頁就能用。
>
> 主持人在螢幕上喊號碼，每個號碼會觸發不同的任務（破冰、找人、分享故事），賓客在手上的小卡圈號碼、搶連線。不需要安裝任何東西，**一個連結搞定一切**。
>
> 👉 **直接開始：** [https://teddy-goprobear.github.io/wedding-bingo/host.html](https://teddy-goprobear.github.io/wedding-bingo/host.html)

---

## 🎯 這個遊戲怎麼玩？

賓果卡上有 1–25 的數字，主持人輪流喊號碼，每個號碼背後是三種類型之一：

| 類型 | 說明 | 範例 |
| :--- | :--- | :--- |
| 🎯 **任務** | 全場一起完成一個小任務，完成才能圈 | 「找到跟你同月生日的人」 |
| 👤 **找人** | 符合條件的人舉手分享故事 | 「曾經吃過新娘做的甜點的人」 |
| ⚪ **沒事** | 直接圈起來，調節節奏用 | — |

先連成 **三條線**（橫、直、斜都算）的人，舉手大喊「**賓果！**」就贏了。

---

## 🚀 三步驟開始用

### Step 1：打開網頁，編輯你的 25 題

打開 [host.html](https://teddy-goprobear.github.io/wedding-bingo/host.html)，你會看到設定頁面，分兩個區塊：

- **上半部**：遊戲規則說明（給你了解玩法用的，不用改）
- **下半部**：1–25 號對照表，**每一行都可以直接改**

| 欄位 | 怎麼改 |
| :--- | :--- |
| 類型 | 下拉選單，選「任務 / 找人 / 沒事」 |
| 內容 | 直接打字，填你自己的題目 |

> 💡 頁面已經預填了一套範例題目，你可以直接改成自己的版本，也可以先玩玩看感受一下。

### Step 2：按「開始遊戲」

編輯完成後，按右上角的 **「開始遊戲」** 或頁面最底部的 **「儲存並開始遊戲 →」**，就會切換到主持人面板。

### Step 3：主持人面板操作

| 功能 | 說明 |
| :--- | :--- |
| **點號碼格子** | 彈出任務卡，唸完內容後按「確認」 |
| **撤回上一步** | 點錯可以退回 |
| **重新開始** | 重新洗牌（會跳確認，不怕誤觸） |
| **返回設定** | 回去改題目內容 |
| **底部音樂列** | 選一首背景音樂，營造派對氣氛 |

## 🃏 賓果小卡怎麼印？

賓客手上需要一張實體賓果卡。打開 [cards.html](https://teddy-goprobear.github.io/wedding-bingo/cards.html)，每頁會生成一張 10cm × 15cm 的小卡，號碼隨機排列，直接列印裁切就能用。

> 💡 每張卡的數字排列不同，這樣才有搶賓果的樂趣。建議多印幾張備用。

## ⚠️ 注意事項

- **編輯的內容存在瀏覽器裡**（localStorage），換裝置或清除瀏覽器資料會消失。建議編輯完截圖備份，婚禮當天用同一台裝置操作。
- 建議用 **電腦或平板** 操作主持人面板，螢幕比較大，賓客也看得到。
- 25 個號碼在宮格上完全隨機排列，每次開始遊戲都會重新洗牌。

## 💡 設計你自己的 25 題的建議

| 題目類型 | 建議數量 | 設計重點 |
| :--- | :--- | :--- |
| 任務型 | 10 題左右 | 讓全場動起來的破冰任務 |
| 找人型 | 6 題左右 | 跟新人有關的趣事，讓認識的人舉手分享 |
| 沒事型 | 9 題左右 | 調節節奏，不要每題都是大任務 |

> 💡 「找人型」的情感濃度最高，適合安排在中後段當作重磅環節。太早出現容易讓後面的任務感覺平淡。

---

## 🙋 有問題？

這個遊戲是用純 HTML + JavaScript 做的，不需要後端、不需要帳號，打開就能用。如果遇到問題：

1. **重新整理頁面**，大部分問題都能解決
2. **換一個瀏覽器試試**（推薦 Chrome 或 Safari）
